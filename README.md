# TradeGuard 交易守门员 (V1.0)

> **交易之前有理由，交易之后守理由。**  
> **你现在做的事情，和当初买它的理由匹配吗？**

TradeGuard 是一个面向个人股票交易者的 Web 端交易纪律与认知偏差管理工具。  
它不负责选股、不预测涨跌、不提供买卖建议。它解决的核心痛点是：**让“买入时的自己”监督“持仓后的自己”**，防止冲动交易、FOMO 追涨、时间尺度错配（短线变长线/中线被震出）与盲目补仓。

---

## ✨ 核心功能矩阵 (基于 PRD V1.0)

### 1. 🏠 今日概览 (Dashboard)
- **状态看板**：实时汇总今日计划交易、临时冲动交易、本周纪律违规数、当前总持仓水位。
- **守门员问讯与铁律轮播**：动态呈现核心纪律箴言（“不要拿中线逻辑买入，却要求短线价格证明自己正确”等）。
- **🔴 账户级熔断警报**：当触发连续亏损、连续计划外交易或单笔/单周回撤超标时，主页自动点亮红色警报模式，提供降低仓位与停机复盘指引。
- **活跃持仓实时速查**：直观展示持股进度与时间尺度对齐状态。

### 2. ➕ 结构化建仓 (我要买入)
- **Step 1 交易类型选择**：
  - **A 产业预期** (数周~数月)：供需反转、行业周期、技术渗透，给予充分发酵时间。
  - **B 事件催化** (数日~数周)：政策、财报、产品发布、大单落地，见光或落地即了结。
  - **C 趋势/情绪** (1~10个交易日)：龙头首板、放量突破、板块共振，严格执行时效。
- **Step 2 严密 ABCT 假说录入**：
  - **A (Alpha)**：我赚的是什么钱？一句话讲清底层因果。
  - **B (Broken)**：什么客观事实发生，证明判断错了？（严禁以“跌了5%”当作证伪）。
  - **C (Continue)**：什么新增客观证据出现，才允许加仓？
  - **T (Time)**：预期验证周期选择与精确起止日期测算。
- **Step 3 仓位与风控计算**：
  - 账户最大冲击公式：$仓位\% \times 最大亏损\% = 账户最大风险\%$。
  - 自动与全局风控阈值比对，超标高亮警告。
- **Step 4 🔥 FOMO 冷静器**：
  - 识别追涨/大涨信号，强制开启 **30 秒倒计时冷静器**与 3 道灵魂自检拷问（买的是预期还是阳线？如果错过有何影响？）。
- **Step 5 买入前 4 项灵魂复选闸门**：
  - 100% 全部确认勾选后方可落库建仓。

### 3. 📊 持仓监控与时间尺度错配检测
- **时间尺度进度仪**：直观对比“已持有天数 / 逻辑验证周期”。
- **错配智能警报**：
  - 产业中长线持有初期（如 4 天）遇价格回调，提醒：“不要拿短线价格波动验证中期产业逻辑！”
  - 短线情绪交易超期，强力警报：“原计划交易窗口已结束，你是否正在把短线修改为长线投资？”
- **每日持仓假设核验**：
  - 核心问讯：“从昨天到今天，有没有出现改变原始交易假设的新信息？”（🟢没有 / 🟡有新信息观察 / 🔴逻辑可能被证伪）。

### 4. 📈 理性加仓模块
- 回显建仓时最初约定的加仓条件。
- 必须勾选并详述 6 大类客观新增证据（行业公开数据/重大订单/财报毛利/供求关系/主力放量等）。
- **破除成本锚定灵魂拷问**：“如果我现在完全没有这只股票，我还会在当前价格买入吗？”若选择“不会”，触发🚨成本锚定风险警告。

### 5. 📉 平仓卖出与交易质量分离
- 9 大离场原因分析（含“因为跌了很难受”、“几天没涨不耐烦”）。
- **情绪化卖出拦截**：强制调取买入初衷与证伪条件，核验“上述证伪事实到底发生没有”。
- **三种止损机制归类**：
  - `Price Stop` (价格止损 - 控制账户财务风险)
  - `Thesis Stop` (逻辑止损 - 假设被客观事实证伪，虽亏犹荣)
  - `Time Stop` (时间止损 - 时间窗口结束，事实未发生)
- **交易质量与收益分离 (Process vs Return)**：
  - 评定过程质量（优秀/正常/轻微瑕疵/严重违规），践行“好交易也会亏钱，坏交易也会赚钱，绝不用结果替行为辩护”。

### 6. ⏱️ 单只标的全生命周期时间轴 (Timeline)
- 决策因果链树状演进图：
  - `建计划` $\to$ `首次买入` $\to$ `跟踪调研事实` $\to$ `新增证据理性加仓` $\to$ `平仓离场`。
- 支持随时追加调研笔记与产业链事实流水。

### 7. 🧠 每日闭市复盘 (Daily Review)
- 收盘后必答 6 问：
  1. 今天有没有计划外交易？
  2. 有没有拿产业逻辑买入，却因短期波动卖出？
  3. 有没有短线被套改长线？
  4. 有没有因浮亏而加仓，而非因新增证据？
  5. 有没有 FOMO 追涨？
  6. 最差交易主要归因与自律备忘录。
- 自动生成零违规成就或纪律偏差流水。

### 8. 📅 周度审计报告 (Weekly Review)
- 聚合近 7 天交易、胜率、盈亏。
- 深度剖析计划执行率、违规分布、错配次数与超额风控标的，输出综合行为等级（S/A/B/C/D）。

### 9. 📈 纪律统计仪表盘 (Discipline Analytics)
- **5 大核心纪律率**：计划交易率、时间尺度匹配率、理性加仓率、情绪交易率、平仓胜率。
- **ECharts 质量-收益散点矩阵**：四象限直观剖析“好交易赚钱”、“好交易亏钱(优质防守)”、“坏交易赚钱(危险毒药)”、“坏交易亏钱”。

### 10. ⚙️ 风控熔断器与离线数据安全 (Settings)
- **熔断参数定制**：单笔风险%、单日最大亏损%、单周最大回撤%、连续亏损笔数、连续计划外笔数。
- **本地优先 Local-First**：纯客户端 IndexedDB，无服务器，隐私安全。
- **备份与恢复**：
  - 一键导出 JSON 完整系统备份。
  - 一键导入恢复数据。
  - 一键导出 CSV 交易台账表格。
  - 内置真实示范案例（西部数据、中际旭创、拓维信息、许继电气等）一键重置。

## 🛠️ 技术栈

- **框架**：React 18 + TypeScript + Vite 5
- **样式**：Tailwind CSS (Notion + Linear 风格：极简深色沉浸、安静克制、高留白)
- **存储**：Dexie.js (IndexedDB 强类型持久化) + `dexie-react-hooks` 实时响应式订阅
- **图表**：ECharts 5 + `echarts-for-react`
- **图标**：`lucide-react`
- **动画与正向反馈**：`canvas-confetti`

## 🚀 启动与运行

确保本地已安装 Node.js 与 pnpm：

```bash
# 1. 安装依赖 (已完成)
pnpm install

# 2. 启动本地开发服务
pnpm dev

# 3. 生产打包构建 (已测试通过)
pnpm build
```

启动后在浏览器中打开控制台输出的地址（如 `http://localhost:5173`）即可立即使用！
首次载入会自动预填充实战示范数据，可随时在“风控与数据”中重置或清空。
